# 系统兼容与验收

本版的**适配目标为 iOS 17–27**，部署下限设置为 iOS 17.0。编译通过不代表所有
系统版本的开发者隧道协议已经验证。请按以下三层理解兼容状态：

1. 源码与 SDK 编译：由 GitHub Actions 检查，使用可用的稳定版 Xcode 26 或更新版。
2. 底层库：保留上游 idevice 静态库，校验 SHA-256；没有声称重写 iOS 27 协议。
3. 真机定位、后台、恢复：需要对应系统的手机实测。本次开发环境为 Windows，尚未完成真机验收。

| 系统 | 配对路径 | 真机验证状态 |
| --- | --- | --- |
| iOS 17.x | 电脑生成 RPPairing，再导入手机 | 待验证，新增部署目标 |
| iOS 18.x | 电脑生成 RPPairing，再导入手机 | 待验证 |
| iOS 26.x | 电脑生成 RPPairing，再导入手机 | 待验证；26+ 启用 Liquid Glass |
| iOS 27.x | 保留上游本机配对入口；也可导入有效 RPPairing | 待验证；本机配对入口与隧道需分别确认 |
| 17–27 范围内的其他系统版本 | 以该系统实际提供的开发者服务为准 | 未单独验证，不作兼容承诺 |

17–25 使用材质背景回退，不依赖 iOS 26 的 Glass API。安装后还需开发者模式、
正确配对文件、LocalDevVPN 和有效签名。该架构不以越狱或 TrollStore 为前提。

## 真机检查步骤

- 记录手机型号、完整 iOS 版本、签名安装方式、LocalDevVPN 版本和网络环境。
- 首次启动检查中文引导、定位/本地网络权限提示、配对导入与设置页。
- 对无效配对文件、SideStore 文件、错误隧道 IP、断开的 VPN，检查中文错误与重试。
- 选点发送后在系统地图中检查位置；记录最后发送时间，不以 App 自己的图钉作为回读证据。
- 在线路运行时停止、切换摇杆、重新选点，检查旧路线没有再次覆盖坐标。
- 检查路线暂停/继续、终点保持、速度倍率与跨日期变更线轨迹。
- 导入多段 GPX、反序属性、单引号属性、二进制/XML RPPairing，检查结果和错误提示。
- 检查 Wi-Fi/蜂窝切换、锁屏、后台、VPN 断开；系统可能限制后台存活时间。
- 点击停止，等待新系统定位；若清除失败，重新连接 VPN 后使用“恢复系统定位”。
- 中国大陆地图、搜索与 GPX 坐标标准需单独验证。本版保留上游坐标传递方式，
  **未自动添加 GCJ-02/WGS-84 转换**，也未宣称修复国内地图偏移。

开发者模拟定位可以被应用识别。系统接收指令不等于第三方应用接受该位置。
